Approach

A dataset is only worth buying if you know what it is and what you may do with it.

  1. Only data we can license. We offer a dataset only when we hold the right to do so. We do not resell material whose terms forbid it.
  2. Provenance recorded. Every dataset has a documented source and collection method.
  3. Terms in plain language. License terms are stated before purchase, not after.
  4. Tested before listing. We read samples by hand and run the checks below.
  5. Limits stated. Each listing says what the data does not cover.

About

Parralax is run by Michael Zhymanov, a machine learning developer.

I write and train models in Python and PyTorch, mostly transformer-based models and computer vision. That work showed me how much a result depends on the dataset: where it came from, how it was labeled, and what its license allows.

Parralax supplies datasets to other people on that basis. The company is new, so listings are added as each dataset is properly licensed and checked. If you are looking for something we don't list yet, ask.
